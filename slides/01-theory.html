Theory · Error recognition

States you must make visible

State What the user should see
ready Input enabled · can send
submitted / streaming In-progress · disable send · optional Stop
error Generic “something went wrong” · retry possible
Tool running “Classifying… querying DB…”: not a frozen blank screen
Don’t leak raw API errors or keys. Recognize the class of failure; keep the UI honest.
