Homework · pick a tier

Keep the Product Alive

Optional stretch after tonight — same bot, still yours. Start with Tier 1, then go further if you want.

Tier 1 · must-do

Deploy

Goal

Get /chat live on the public internet.

How to
  1. Push the repo · deploy on Vercel
  2. Add OPENAI_API_KEY + DATABASE_URL as server env — never NEXT_PUBLIC_
  3. Open the URL · ask one golden · share the link
Tier 2 · stretch

MCP wrap

Goal

Expose the same lib/queries helpers as MCP tools (tonight called them directly).

How to
  1. Tools: list_races, get_start_list, count_riders
  2. Use @modelcontextprotocol/sdk + @ai-sdk/mcp
  3. Attach from /api/chat · follow mcp/README.md
Tier 3 · polish

Product polish

Goal

Make it feel shipped — not a lab demo.

How to
  1. Clearer errors + retry · working Stop
  2. Render assistant replies as markdown
  3. Tiny eval: run data/golden-questions.md
