Step 4 · Decisions API

experimental_decide + choice

lib/classify.ts (sketch) 
import { experimental_decide } from 'ai';
import { openai } from '@ai-sdk/openai';

const { answers } = await experimental_decide({
  model: openai.decisionModel('gpt-6-luna'),
  state: { question: userText },
  questions: {
    intent: {
      type: 'choice',
      instructions: 'Pick the SQL branch for this season question.',
      criteria: {
        list_races: 'Calendar overview',
        start_list: 'Who rides a named race',
        count_riders: 'How many riders',
        refuse: 'Off-domain / impossible',
      },
    },
  },
});
// answers.intent.choice → lib/queries.ts · raceHint via heuristics

install npm i ai @ai-sdk/openai postgres

gpt-6-luna = OpenAI Decisions model (AI SDK docs) — not the same as OPENAI_MODEL for streamText. Heuristics (or Responses later) fill free-text race hints.
